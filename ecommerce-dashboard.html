🛍️ Nova Compra

A compra é uma saga executada pelo Step Functions: pedido → reserva de estoque → pagamento → baixa da reserva → confirmação. Se um passo falhar, ele e os anteriores são desfeitos (compensação).

Para ver a compensação: compre o produto Server (pagamento recusado acima de R$ 10.000) ou uma quantidade maior que o estoque.
